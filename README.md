# MangaReader - 本地漫画阅读器
如有问题或者意见反馈，以及一切关于本项目的探讨，欢迎与我联系
作者微信18955137046，qq：1905182383

一款基于 Android Jetpack Compose 的本地漫画阅读器，采用「内容优先，UI 隐形」的设计理念，支持多种漫画格式与沉浸式阅读体验。

> 本项目为个人作品，欢迎试用、提 Issue 或提交 PR。

## 主要特性

- **多格式支持**：CBZ/ZIP、CBR/RAR、CB7/7Z、CBT/TAR、EPUB、PDF、MOBI/AZW/AZW3、图片文件夹
- **小说文本阅读**：支持文本型 MOBI/AZW3，包括 Huffman + CDIC 字典压缩（compression 17480）；漫画型与小说型 MOBI 均可正常打开
- **书架管理**：以文件夹为单位管理漫画系列，子文件作为分卷/章节
- **筛选与排序**：按收藏/未读/在读/已读/新增及分类筛选，支持按名称/最近阅读/进度排序；筛选或搜索无匹配项时提示并提供「清除筛选」入口
- **分卷浏览**：进入漫画先展示分卷缩略图（Perfect Viewer 风格）
- **多种阅读模式**：单页、双页、垂直滚动、水平滚动，支持日漫 RTL
- **画面优化**：亮度/对比度/Gamma/饱和度、自动裁白边、灰度、锐化、降噪、镜像、旋转
- **大范围内存缓存**：阅读时自动预加载当前页前后各 15 页，退出阅读自动释放
- **手势热区**：左/右翻页、中央呼出菜单，热区大小可调
- **主题皮肤**：经典黑、牛皮纸、赛博朋克、护眼绿、酒红幕
- **阅读进度**：自动保存页码与书签；翻页进度写入带 400ms 防抖，快速翻页时减少 IO 与耗电，退出阅读时兜底 flush
- **阅读统计**：按日/周/月统计阅读页数与时长，支持阅读目标
- **WebDAV 同步**：配置服务器后可自动同步阅读进度、书签、收藏到多端
- **缓存管理**：设置页可按漫画清理缓存、查看页面/缩略图/分享源文件/崩溃日志导出等临时文件大小；切换漫画时仅清理旧漫画缓存，保留其他漫画跨会话缓存；退出应用时释放缓存后台协程与 trim 线程
- **稳定性优化**：滤镜链安全回收中间 Bitmap、阅读统计旧数据裁剪、退出保存/WebDAV 同步加超时兜底；各格式解析器与封面提取按屏幕分辨率采样解码，并通过公共 Bitmap 池复用 inBitmap，降低 OOM 与 GC 抖动
- **分享安全**：FileProvider 仅暴露 `source_share`、`share_cards`、`crash_logs` 三个缓存子目录，避免外部应用读取其他缓存与配置；分享源文件复制前净化文件名，防止目录遍历
- **本地备份安全**：JSON 备份不包含 WebDAV 等账号密码（密码单独加密存储），降低备份文件泄露风险；导入时校验备份版本，拒绝过低版本并预留迁移钩子
- **SMB/NAS 流式阅读**：入口已预留（浏览 HTTP 文件列表，直接打开远程漫画待完善）



## 环境要求

- Android Studio Hedgehog (2023.1.1) 或更高版本
- JDK 17
- Android SDK 34（编译）/ 26（最低运行）

## 构建与运行

项目使用本地 Gradle Wrapper：

```bash
# 构建 debug APK
.\gradlew assembleDebug

# 安装到已连接设备
.\gradlew installDebug

# 清理构建缓存
.\gradlew clean
```

构建成功后 APK 位于：

```
app/build/outputs/apk/debug/app-debug.apk
```

## 使用说明

1. **添加书架**：首次打开后，点击右上角 **+** 选择一个本地文件夹作为书架目录；支持添加多个书架并在顶部下拉切换。若系统无法保存该目录的持久访问权限，会提示重新选择。
2. **浏览漫画**：书架中的子文件夹会被视为漫画系列（COMIC_BOOK），独立压缩包/PDF 会直接显示为单本漫画。
3. **分卷阅读**：点击漫画进入分卷浏览，选择分卷后自动恢复至上次的阅读页。
4. **阅读手势**：默认全屏零 UI，点击屏幕中央唤出菜单；左/右 1/3 热区翻页（RTL 模式下互换）。
5. **阅读设置**：阅读界面菜单或系统设置页中可调整翻页模式、双页、RTL、亮度/对比度/Gamma、自动裁边、手势热区等；手势设置保存完成后再返回，避免杀进程丢失配置。
6. **缓存管理**：设置 → 缓存管理，可查看页面缓存、缩略图缓存、分享卡片/源文件、崩溃日志导出等临时文件大小，按类型或全部清理；切换漫画时仅自动清理旧漫画缓存，不影响其他漫画。
7. **WebDAV 同步**：设置 → WebDAV 同步，填写服务器地址、账号、密码并选择同步间隔；后台同步带 5 分钟超时，失败自动按指数退避重试。
8. **阅读统计与目标**：设置 → 阅读统计，查看日/周/月阅读数据；设置 → 阅读目标，设定每日页数/时长目标。统计日级数据自动保留最近 2 年。
9. **本地备份/恢复**：设置页支持导出/导入 JSON 备份文件，合并或覆盖本地阅读进度、书签、收藏、分类、书单、阅读统计等数据；备份文件不包含 WebDAV 等账号密码。导入时会校验备份版本，过低版本将被拒绝，未来版本备份会尝试兼容导入。
10. **画面优化安全**：开启夜览/护眼/锐化/降噪后，滤镜链路会自动管理中间 Bitmap；极端内存不足时降级到 RGB_565 或回退原图，降低大图滤镜闪退概率。

更多细节请参考项目内的 [CODE_WIKI.md](./CODE_WIKI.md)。

## 已知限制
